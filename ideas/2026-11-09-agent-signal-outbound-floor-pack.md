## Concept

Sell a **same-week agent signal-based outbound floor pack** when a solopreneur, indie hacker, or freelance operator wants an agent to watch tier-1 accounts for buying intent and route only warm opportunities into a sales workflow—without building the whole system or letting the agent send cold outreach unchecked.

The customer uploads (or pastes):

- tier-1 account list (companies or named buyers) and any existing CRM export
- current or proposed signal definitions (funding, job posts, tech installs, content engagement, etc.)
- list of data sources they already have or are willing to use
- optional: sample of a previous failed outbound agent run or “it just spammed”

Agents plus one human operator return within 48–72 hours:

1. Signal inventory and rules: every proposed signal tagged must-have / nice-to-have / never, with a written “why this counts as intent” sentence and a negative-signal list.
2. Data-source map: which sources feed which signals, frequency of checks, and fallback if a source is unavailable.
3. Human-approval gate template: paste-ready prompt or wrapper language that forces a review step before any email, LinkedIn message, or CRM write that touches a live contact.
4. Routing workflow: ordered steps from “signal fired” to “warm opportunity in inbox/CRM with citation of the exact signal evidence.”
5. Source ledger: every recommendation cites the provided materials or is marked operator assumption.
6. Starter prompt / SKILL.md fragment the solo can drop into their existing agent harness.

This is **not** a full outbound SaaS, **not** live data-source integrations, **not** a cold-email sequence writer, and **not** a general sales-automation audit. It is a productized desk that turns “I want the signal agent that actually works” into an inspectable floor the solo can implement this week.

## Target user

- Primary buyer: solopreneurs, indie hackers, and freelance operators (EU/UK/US/Canada) already running or about to run agents for lead gen, who have a short list of tier-1 accounts and do not want a data engineer on retainer.
- Urgent pain: the agent either never surfaces anything useful or blasts cold messages; the operator cannot tell which signals are worth watching or where the human gate should sit.
- Existing workaround: manual daily checks in Clay/Apollo/LinkedIn, or a chatbot that drafts sequences with no signal evidence.

## Why this works

- Market signal: today’s posts treat signal-based outbound with human gates as the rare agent pattern that ships and moves revenue. The missing artifact is a cited floor derived from the buyer’s actual accounts and signals.
- Agent advantage: parse account lists and signal notes, draft the inventory, source map, gate language, and routing steps overnight.
- Solo-operator advantage: one person who has watched agents either spam or stay silent can tighten the signal rules and approval language to real sales cost and deliver a pack implementable in under 45 minutes of review.

## Execution plan (one person + agents)

**Agent 1 — Intake.** Accept account lists, signal notes, data-source lists, and any prior-run examples. Normalize, assign ids, flag missing ownership or approval info.

**Agent 2 — Signal & source mapper.** Extract proposed signals, propose must-have/never rules, map to available sources, and tag with citations.

**Agent 3 — Gate & routing writer.** Draft the human-approval prompt language and the ordered routing workflow from signal to warm opportunity.

**Agent 4 — Starter fragment writer.** Produce the paste-ready prompt or SKILL.md fragment.

**Human operator.** Remove vague signals, tighten gates to real send cost, confirm every claim is checkable against the materials, and export Markdown + PDF. Do not connect live data sources or send messages yourself.

Stack to start: existing coding/browser agents, one LLM, plain Markdown, Stripe Payment Link, mailbox. No product UI until the fifth paid job.

## Risks and mitigations

- Invented signals or data sources: every item cites provided materials or is marked “not specified — operator assumption.” Operator rejects drafts that invent run behavior.
- Confidential account lists: isolated processing, no training on client materials, delete after 30 days unless they opt in.
- Overlap with external-action lease or autonomy-threshold packs: this pack is specifically the signal-definition + watch + human-gate-before-send pattern for outbound. Capability leases and general autonomy thresholds stay separate. Implementation stays with the buyer.
- Buyer expects live integrations or a full Clay replacement: deliver the pack for the materials provided and stop. Connecting sources or writing sequences is a separate engagement.
- Thin materials: if the customer has only “watch my accounts” and no list or signal ideas, return a short gap list and partial refund rather than invent a floor.
