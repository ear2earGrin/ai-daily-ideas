## Concept

Sell a **same-week ship receipt + distribution floor pack** when a solo just shipped (or is about to ship) a product, agent, or marketplace listing and has no cited story to post.

The customer uploads or exports:

- the ship window: git log / changelog / Product Hunt draft / marketplace listing / 4-minute voice note
- artifacts: screenshots, demo URL, before/after, one invoice or usage line if they claim revenue
- optional: last three posts that flopped, so the pack does not repeat the empty slogan

Agents plus one human operator return within 48 hours:

1. A ship receipt: one sentence of what actually shipped, dated, with source ids. Claims without an artifact are tagged `not-in-record`.
2. A claim ledger: each marketing sentence mapped to `shown` / `demo-only` / `hoped-for` / `not-in-record`.
3. One X thread (5-8 posts) and one LinkedIn post written only from `shown` cells.
4. A 7-day distribution floor: 7 short posts tied to remaining artifacts (one screenshot, one fail, one customer quote if present, one "what is still broken").
5. Marketplace / PH listing copy that deletes 70%-revenue and "powerful AI agent" language unless the receipt supports it.
6. A source appendix. No invented ARR. No fake user counts.

This is **not** a social scheduler, **not** a growth agency, and **not** a marketplace. It is a productized desk for *one ship week*.

## Execution plan (one person + agents)

**Agent 1 — Intake.** Accept zip/git patch/PNG/PDF/URL/voice. Detect the single ship under review.

**Agent 2 — Artifact miner.** Map files to claims. Tag each claim `shown` / `demo-only` / `hoped-for` / `not-in-record`.

**Agent 3 — Channel writer.** Draft X thread, LinkedIn post, listing copy. Every sentence cites a receipt row.

**Agent 4 — Floor planner.** 7 follow-ups, each tied to an unused artifact. Leave days blank rather than invent.

**Human operator.** Kill fake metrics, drop secrets, export PDF + Markdown + copy-paste posts. The model does not post to their accounts.
