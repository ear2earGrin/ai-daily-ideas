## Concept

Sell a **same-week buyer-agent visibility pack** when a solopreneur, freelancer, or 1-5 person shop is being (or wants to be) recommended by ChatGPT, Perplexity, or another operator's prospecting agent — and their site still reads like a 2019 brochure.

The customer uploads or points at:

- public URLs: homepage, pricing, docs, FAQ, booking, changelog, privacy
- optional existing `llms.txt`, `robots.txt`, sitemap, MCP/OpenAPI, schema.org JSON-LD
- optional: last 7 days of "how did you find us" notes, answer-engine screenshots, or a competitor URL they keep losing to

Agents plus one human operator return within 48 hours:

1. A visibility scorecard: `findable` / `parseable` / `priced` / `bookable` / `trustable` / `not-in-record` for each public surface.
2. A citation ledger: what an answer engine can currently quote (legal name, offer, price, SLA, jurisdiction, contact) vs what it invents.
3. A gap list of 7 fixes that fit one week: missing price floor, missing cancellation rule, unreadable PDF-only menu, no machine contact, stale hours, no `llms.txt`, MCP that 401s a first call.
4. A draft `llms.txt` (and optional one-page `agents.md`) the shop can paste to root. Every line cites a live URL or is marked `draft-unverified`.
5. A first-call card: the single safe action a buyer-agent should take (book a slot, request a quote, pay a listed SKU) and the three actions it must not take.
6. A source appendix. No invented schema.org types. No "just add MCP and you will rank."

This is **not** an SEO agency, **not** a live MCP host, and **not** an answer-engine ads product. It is a productized desk for *one shop, one week*, so a purchasing agent has something true to read.

## Target user

- Primary buyer: EU/UK/US solopreneurs, indie hackers, freelance shops, and local 1-5 person vendors who already sell online and keep hearing that "agents will find you."
- Urgent pain: ChatGPT recommends a competitor, a prospecting agent cannot extract a price, or their only machine surface is a contact form that dumps to an unread inbox.
- Existing workaround: write a blog post titled "we use AI," paste the homepage into ChatGPT and hope, or publish an empty `llms.txt` copied from a template.

## Why this works

- Market signal: today's X feed named agent visibility, MCP/`llms.txt`, trust, and the death of unread cold email. Tool-marketplace packs do not tell a cafe or a freelance studio what to put on their own origin.
- Agent advantage: fetch public pages, refuse to invent prices, draft a cited `llms.txt`, score what a buyer-agent can actually do on the first call.
- Solo-operator advantage: one person who has watched an agent hallucinate a shop's hours can write a first-call card a vendor will follow. Judgment about what must stay human-gated is the product; the model is the clerk.

## Execution plan (one person + agents)

**Agent 1 — Intake.** Accept URL list + optional exports. Detect a single origin. Refuse to audit a 40-page marketplace in one pack.

**Agent 2 — Public crawler.** Fetch homepage, pricing, docs, FAQ, robots, sitemap, `llms.txt` if present. Tag each fact `on-page` / `in-pdf-only` / `not-in-record`.

**Agent 3 — Answer-engine probe.** Ask 5 buyer questions in a fresh session (what they sell, price floor, how to book, cancellation, jurisdiction). Quote the model's answer next to the live page. Do not log into customer tools.

**Agent 4 — Pack writer.** Scorecard, gap list, draft `llms.txt`, first-call card. Every cell has a source URL or `not-in-record`.

**Human operator.** Kill fake ranking promises, drop secrets, export PDF + Markdown. The model does not publish to their origin and does not stand up their MCP server.

Stack to start: coding + browser agents, one LLM, Stripe Payment Link, a mailbox. Public URLs only in week one.

## Risks and mitigations

- Fake SEO claims: never promise ChatGPT or Perplexity ranking. Report what they *currently* say and what the origin actually contains.
- Overlap with agent-payable tool listing (2026-09-16): that pack lists a *tool* for other agents to pay. This pack makes a *shop origin* readable. Sell both; do not merge the files.
- Overlap with ship-receipt distribution (2026-09-23): that pack turns this week's ship artifacts into posts. This pack turns the standing public site into something a buyer-agent can cite.
- Overlap with problem-intent replies (2026-09-09): that pack writes human replies in threads. This pack does not post in threads.
- Stale crawl: timestamp every fetch. If a page 404s mid-pack, mark `not-in-record` instead of using cache as truth.
- Scope creep into hosting their MCP: draft the first-call card. Stop.
