## Concept

Sell a **same-week one-job agent charter pack** when a solopreneur, freelancer, or 1-5 person shop already has 2–8 agents / GPTs / OpenClaw bots / n8n agent nodes running — and the only spec is a Slack thread that says "just handle it."

The customer uploads or points at:

- a list of live agents (name, host, what they *think* it does)
- tool / integration list (inbox, CRM, calendar, Stripe, browser, shop admin)
- last 7 days of traces, cron times, or sample runs they are willing to share
- optional: one blow-up (sent the wrong reply, booked the wrong slot, promised a price)

Agents plus one human operator return within 48 hours:

1. A job floor: each agent tagged `one-job-clear` / `job-overlap` / `personality-only` / `not-in-record`.
2. A charter card per agent (max 6 in pack one): one sentence job, one schedule, allowed tools, attached skill bullets, irreversible actions that must pause, owner who reviews.
3. A last-7-day receipt: runs that matched the job vs runs that wandered. Numbers only from their traces or marked `draft-unverified`.
4. A 7-line morning card: which bot worked, which bot invented a second job, what stayed paused, what the human must review before 10:00.
5. A first-week script: freeze one bot to a single job tonight; park one overlapping bot; attach one skill file; do not add a seventh agent.
6. A source appendix. No invented hours saved. No "set it and forget it."

This is **not** a hosted agent platform, **not** an OpenClaw installer, and **not** a 24/7 monitoring SaaS. It is a productized desk for *one shop, one week of live bots*, so "give it a job" is a file instead of a tweet.

## Target user

- Primary buyer: EU/UK/US indie hackers, freelance ops builders, and small shops who stood up OpenClaw / Hermes / custom GPTs / n8n agents in the last 90 days and now have a pile of bots with no written job.
- Urgent pain: one bot researches *and* sends *and* invoices; another answers the phone with no pause list; the owner cannot say which agent is allowed to talk to customers after 22:00.
- Existing workaround: rename the bot in Discord, paste the system prompt into ChatGPT and ask "is this safe," or turn everything off on Sunday night.

## Why this works

- Market signal: this week's X feed named one-bot-one-job-one-schedule, skills as reusable constraints, humans as reviewers, capability-without-governance on the factory floor, and vertical jobs the big platforms only half-solve. Existing catalog packs cover *new* agent probation, *who owns* a surface, *which DAG step* may self-heal, and *which skill* to harvest from traces — not the written job charter for the bots already running.
- Agent advantage: read messy traces and tool lists; refuse to invent a second job; draft a charter a human will pin in Notion.
- Solo-operator advantage: one person who has watched a bot invent a second job can kill the overlap in ten minutes. Judgment about what must stay one job is the product; the model is the clerk.

## Execution plan (one person + agents)

**Agent 1 — Intake.** Accept the agent list + tool list + traces. Detect one shop. Refuse to charter a 20-bot agency in one pack.

**Agent 2 — Job splitter.** Read what each bot actually did in the last 7 days. Tag one-job vs overlap vs personality-only. Never log into their OpenClaw / n8n / GPT host.

**Agent 3 — Pause clerk.** Mark email-out, money, calendar writes, CRM writes, and logins as human-review unless the record shows a written Approve rule.

**Agent 4 — Pack writer.** Job floor, charter cards, 7-day receipt, morning card, first-week script. Every number cites a trace or `draft-unverified`.

**Human operator.** Kill fake hour-saved math, drop secrets, export PDF + Markdown. The model does not deploy a bot and does not click Send.

Stack to start: coding + browser agents, one LLM, Stripe Payment Link, a mailbox. Exports and screenshots only in week one.

## Risks and mitigations

- Acting as their agent engineer: never connect to their host. Draft the charter. They paste the pauses.
- Overlap with probation onboarding (2026-09-23): that pack is a *new* agent's first week. This pack is the written job for bots already live.
- Overlap with collision map (2026-09-22): that pack is two agents claiming the same surface. This pack is whether *one* agent has more than one job.
- Overlap with approval-lane (2026-09-19): that pack is who may write. This pack is what the job even is.
- Overlap with skill harvest (2026-09-19): that pack extracts reusable skills from traces. This pack attaches one short skill to a single job.
- Overlap with overnight ops (2026-09-25): that pack is the sleep window and spend kill. This pack is the job description inside that window.
- Secret-stuffed traces: strip credentials before processing. Halt if live tokens appear.
- Scope creep into building the sixth agent: deliver the floor. Stop.
